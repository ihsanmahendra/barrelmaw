# Barrelmaw

**Play it in your browser: https://ihsanmahendra.github.io/barrelmaw/**

A pirate card-and-puzzle game made with Godot 4.7 (web first, Android later). Smash colored barrels with
cannonballs, play cards to change how they fire, and sail a 100-stage treasure map (50 day stages, 50 night stages).

- Game project: [`prototype/`](prototype/) (open the folder in Godot 4.7, or see `prototype/README.md`)
- Concept brief: [`design/concept-brief.md`](design/concept-brief.md)

## Run
Open `prototype/` in Godot 4.7 and press Play, or export the web build with `bash prototype/tools/export_web.sh`
(needs the Godot 4.7.2 export templates).
